Save Playlist to Your Library (+/✓) Button

This Spotify-inspired microinteraction is represented by a plus button. Clicking it switches the button to a green checkmark to indicate the saved state. Clicking again returns it to the unsaved state.

TRIGGERS
  • Hover On
  • Hover Off
  • Click On
  • Click Off
RULES
  • Hover On: Cursor changes, icon brightens and a tooltip appears.
  • Hover Off: The cursor changes back to an arrow,tooltip disappears and the icon returns to its normal appearance.
  • Click On: The plus button to switch to the saved state. Clicking the plus changes it to a green checkmark. and stars fade in
  • Click Off:Clicks the checkmark button to switch back to the unsaved state.
FEEDBACK
  • Hover On: Cursor changes, icon brightens and a tooltip appears.
  • Hover Off: The cursor changes back to an arrow, tooltip disappears and the icon returns to its normal appearance.
  • Click On: Clicks the plus button to switch to the saved state. Clicking the plus changes it to a green checkmark. and stars fade in
  • Click Off: The checkmark changes to a plus sign
LOOPS & MODES
  • No loops
