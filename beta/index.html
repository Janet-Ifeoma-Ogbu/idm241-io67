1. Smart Shuffle Preview

Preview three suggested songs before enabling Shuffle.

TRIGGERS
  • Hover On
  • Hover Off
  • Click On
  • Click Enable
  • Click Off
RULES
  • Hover On: The cursor changes to a hand and the Shuffle button changes appearance.
  • Hover Off: The cursor changes back to an arrow and the Shuffle button returns to its normal appearance.
  • Click On: A preview panel appears with three suggested songs.
  • Click Enable: The preview panel disappears, the Shuffle icon turns green and the message changes to "Shuffle is on."
  • Click Off: The Shuffle icon returns to its normal color and the message changes to "Shuffle is off."
FEEDBACK

2. Add to Queue with Counter

Add sample songs and see the queue counter update.

TRIGGERS
  • Hover On
  • Hover Off
  • Click Add
  • Click View
  • Click Close
RULES
  • Hover On: The cursor changes to a hand and the button changes appearance.
  • Hover Off: The cursor changes back to an arrow and the button returns to its normal appearance.
  • Click Add: The song title appears in the queue confirmation message and the counter increases by one.
  • Click View: The queue panel appears and shows the songs in the queue.
  • Click Close: The queue panel disappears, but the songs remain in the queue.
FEEDBACK
  • Hover On: The cursor changes to a hand and the button changes appearance.
  • Hover Off: The cursor changes back to an arrow and the button returns to its normal appearance.
  • Click Add: The song title appears in the queue confirmation message and the counter increases by one.
  • Click View: The queue panel appears and shows the songs in the queue.
  • Click Close: The queue panel disappears, but the songs remain in the queue.
